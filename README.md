# 🌦️ WeatherAPI

A simple and responsive **Weather Application** built using **HTML, CSS, and JavaScript**.

The application uses a weather API to fetch real-time weather information based on the location entered by the user.

## 🚀 Features

* 🌍 Search weather by city
* 🌡️ Display current temperature
* ☁️ Display weather conditions
* 💧 Display humidity
* 💨 Display wind speed
* 🔄 Fetch real-time weather data using an API
* 📱 Responsive user interface
* ⚡ Simple and easy-to-use design

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and API integration
* **Weather API** – Fetching real-time weather data

## 📁 Project Structure

```text
WeatherAPI/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

### `index.html`

Contains the structure and elements of the weather application.

### `style.css`

Contains the styling, layout, colors, animations, and responsive design.

### `script.js`

Contains the JavaScript logic used to:

* Get the city entered by the user
* Send a request to the Weather API
* Process the API response
* Display weather information dynamically

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/syedmuddassir09/WeatherAPI.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd WeatherAPI
```

### 3. Run the application

Simply open:

```text
index.html
```

in your web browser.

You can also use **VS Code Live Server** for a better development experience.

## 🔑 API Key

This project requires a Weather API key if the API service you are using requires authentication.

Add your API key in `script.js` according to the API provider's requirements.

**Important:** Do not upload private API keys to a public GitHub repository.

For production applications, API keys should be stored securely using a backend server or another secure method.

## 🔄 How It Works

```text
User enters city
       ↓
JavaScript receives the city
       ↓
Weather API request
       ↓
API returns weather data
       ↓
JavaScript processes the response
       ↓
Weather information displayed
```

The application provides a simple interface where users can enter a city and retrieve its current weather information.
